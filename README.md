# InternNova-Week6
InternNova Week 6 Final Python Project - Student Management System
Project Description

This is a Python project developed for the InternNova Week 6 internship.

Features

- Add student details
- View student records
- Search for students
- Delete student records
- Save student data using JSON

Technologies Used

- Python
- Pydroid 3
- GitHub

Python Concepts Used

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists
- Classes and objects
- File handling
- Exception handling

How to Run

Open main.py in Pydroid 3 and tap Run.
